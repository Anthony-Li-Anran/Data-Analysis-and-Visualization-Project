## 讲稿（照念即可，约 130 字）

先看总量。蓝线是实际投运，2026 年累计 **1475 万 H100 等效**；红线是承诺，2028 年冲到 **6688 万**。两条线之间那块阴影就是缺口，**兑现率只有 22%**。

换个口径看同一件事：按功率算，当前 14.2 GW、承诺 38.2 GW，管线倍数 **2.69 倍**——和组里 README 已经写的一致。

两个口径差在哪？承诺隐含的芯片密度比实际高 **66%**，所以 4.55 倍里有一部分是"未来用更密芯片"的技术假设，不是物理工程量。

## 这页只需要记住两个数

| 算力口径 | 功率口径 |
|---|---|
| 兑现率 22%、4.55× | 兑现率 37%、2.69× |
